Goal: Build a mobile-first Meal Book / Meal Decider web app in React that matches the provided screenshot’s look/flow. Use Vite + React + Tailwind CSS, React Router, and the Firebase v10 Modular SDK (Firestore + Storage). The app must be deployable to Netlify with SPA routing, and all create/edit/delete actions should persist to Firebase. Images should be uploaded to Firebase Storage; recipe metadata to Firestore.

Firebase Integration

Initialize Firebase with env vars (no hardcoded keys).

Use Firestore for all recipe and week plan data.

Use Firebase Storage for image uploads:

On Add/Edit, allow selecting an image file, upload to recipes/{uuid}/{filename}, store imageUrl & imagePath.

On Delete recipe, also delete Storage file if present.

Authentication: implement minimal Anonymous Auth so uid exists for bookmarks and week plan. (No UI sign-in needed.)

Security Rules (include a file firestore.rules and storage.rules):

Allow reads to everyone.

Writes allowed if request.auth != null.

A user can edit/delete recipes they created (resource.data.createdBy == request.auth.uid) or create new.

A user can write their own weekPlans/{uid} only if request.auth.uid == resource.id.

Storage: write only under recipes/{uid}/... when request.auth.uid == uid.

Features & Behavior

Search filters by title, tags, and ingredient names (client-side filter is fine; add a Firestore query if easy).

Category filter chips instantly filter by mealType. Default “All”.

Add Recipe:

Form with title (required), mealType (required), tags (comma input), ingredients (repeatable rows), steps (repeatable), image upload (optional but encouraged).

Use React Hook Form + Zod for validation.

Edit Recipe: prefill; allow image replacement (delete old storage file).

Bookmarks:

Click heart/bookmark icon toggles current user in bookmarkedBy.

/bookmarks lists current user’s bookmarked recipes.

Week Plan:

For each day: breakfast/lunch/dinner slot with “Add” button to pick from your recipes (modal picker with search).

Persist on change; indicate success.

Recipe Details:

Show cover image, meal type chip, ingredients list, steps (ordered), tags, and actions (Bookmark / Edit / Delete).

Empty states for zero recipes, zero bookmarks, and empty week plan.
